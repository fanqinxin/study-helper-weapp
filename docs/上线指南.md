面向当前状态：**个人主体 + 体验版内测 + 不提供付费**。
按这份文档的顺序执行，今天就能在真机上跑通全链路。

如果你想直接提审公开上线，先看第五节——个人主体在当前功能形态下会被三条硬规则同时卡住。

## 二、服务器侧准备（10 分钟）

### 1. 额度给足

个人主体开不了微信支付，页面也没有购买入口。所以额度必须一次给够，否则用户会卡在「次数用完了」却无路可走。

```bash
cd /path/to/project
grep QUOTA_FREE_TOTAL .env      # 应显示 500（模板已改成 500）
```

如果还是 20，改掉并重启：

```bash
sed -i 's/^QUOTA_FREE_TOTAL=.*/QUOTA_FREE_TOTAL=500/' .env
sed -i 's/^QUOTA_WARN_THRESHOLD=.*/QUOTA_WARN_THRESHOLD=10/' .env
docker compose up -d api worker
```

> **注意**：`QUOTA_FREE_TOTAL` 只影响**新建账号**。已经注册过的账号，
> `quota_account` 表里存的是注册时的值，不会自动变。手动补一下：
>
> ```bash
> docker compose exec mysql mysql -ustudy -p"$MYSQL_PASSWORD" study_helper \
>   -e "UPDATE quota_account SET free_total = 500, free_used = 0;"
> ```

### 2. 确认教材数据已灌入

```bash
docker compose exec mysql mysql -ustudy -p"$MYSQL_PASSWORD" study_helper \
  -e "SELECT COUNT(*) AS lesson FROM lesson; SELECT COUNT(*) AS question FROM question;"
# 期望：32 / 96
```

如果是 0，先灌数据（详见 `docs/教材数据维护.md`）：

```bash
docker compose --profile tools run --rm seed
```

### 3. 确认后端与域名都通

```bash
# 宿主机直连后端
curl -s http://127.0.0.1:3000/api/v1/health

# 走 Nginx + 证书
curl -s https://sh-api.rstu.top/api/v1/health

# 证书域名是否匹配
echo | openssl s_client -connect sh-api.rstu.top:443 -servername sh-api.rstu.top 2>/dev/null \
  | openssl x509 -noout -subject -dates
```

三项都正常再往下走。**这一步不通，后面所有步骤都是白折腾。**

## 三、微信后台配置（关键，漏一项真机就报错）

登录 [微信公众平台](https://mp.weixin.qq.com) → 你的小程序。

### 1. 服务器域名（3 处，都必须填）

开发 → 开发管理 → 开发设置 → 服务器域名：

| 类型 | 填什么 |
| --- | --- |
| request 合法域名 | `https://sh-api.rstu.top` |
| uploadFile 合法域名 | `https://sh-api.rstu.top` |
| downloadFile 合法域名 | `https://sh-api.rstu.top` |

> 精确匹配，不能填主域名 `rstu.top`。每月只能改 5 次。

### 2. 用户隐私保护指引（**漏了拍照功能直接不可用**）

设置 → 服务内容声明 → 用户隐私保护指引。

这一步经常被忽略，但后果很硬：**未声明时 `wx.chooseImage` / `wx.chooseMedia` 在真机上会直接调用失败**，作业上传整个功能是死的，而且报错信息很含糊。

按代码实际行为，只需要勾选这两项：

| 声明项 | 对应代码 | 填写用途 |
| --- | --- | --- |
| 选中的照片或视频信息 | `wx.chooseImage`（7 处）、`wx.chooseMedia` | 上传作业照片给 AI 批改、识别自定义教材目录 |
| 摄像头 | 拍照上传作业 | 拍摄纸质作业用于批改 |

**不要多勾**。手机号、位置、通讯录、微信昵称头像这些代码里都没有用到，勾了属于超范围收集，反而会被质疑。

同时在指引里填一份隐私说明，可以直接引用小程序内「我的 → 隐私政策」的内容。

### 3. 添加体验成员

管理 → 成员管理 → 体验成员，把要测试的微信号加进去。

个人未认证主体通常上限 15 人（以后台提示为准）。加上你自己和家长的账号。

### 4. 确认 AppID

`project.config.json` 里是 `wxc3a841df82062e57`，与后台一致即可。

## 四、上传与验收

### 1. 上传代码

微信开发者工具 → 打开本项目根目录 → 右上「上传」：

- 版本号：`1.0.0`
- 项目备注：`内测首版：课文同步练习 / AI 批改 / 错题 / 计划 / 家长端`

前提：`miniprogram/config/index.js` 的 `CURRENT` 是 `'prod'`（已改好）。

上传前先在工具里点「编译」跑一遍，确认没有报错。

### 2. 设为体验版

公众平台 → 管理 → 版本管理 → 开发版本 → 找到刚上传的版本 → 「选为体验版」。

### 3. 真机验收清单

用体验成员的微信扫码打开，**按这个顺序走，前一步不过不要往后走**：

| # | 步骤 | 通过标准 | 不过说明什么 |
| --- | --- | --- | --- |
| 1 | 打开小程序 | 能进首页，无白屏 | 域名 / 证书 / 后端 三者之一有问题 |
| 2 | 自动登录 | 首页出现昵称或默认头像，不再转圈 | `wx.login` 或后端 `/auth/login` 失败 |
| 3 | 选教材 | 能看到「北师大版 语文 一年级上册」 | 教材数据没灌进库 |
| 4 | 进课文列表 | 出现 32 篇课文 | `textbookId` 没写进 user 表 |
| 5 | 做一课练习 | 能答题、能出对错、能得分 | 判分逻辑或题目数据有问题 |
| 6 | 拍照上传作业 | 能拉起相机/相册，能上传成功 | **隐私保护指引没配**（最常见） |
| 7 | 等待批改 | 处理页有进度，最终出报告 | AI Key 没配 / worker 没起 / 额度不足 |
| 8 | 看错题 | 错题进了错题本，有知识点标签 | 批改结果落库失败 |
| 9 | 看学习计划 | 有今日 3 件事 | 计划生成失败 |
| 10 | 家长端 | 切换家长、绑定孩子、看周报 | 家庭绑定链路问题 |

### 4. 出问题先看这三处

```bash
docker compose logs -f api      # 接口报错
docker compose logs -f worker   # 批改任务
docker compose ps               # 容器是否都 healthy
```

Nginx 侧看日志里 `urt`（上游耗时）：有值说明请求到了后端，为空说明根本没连上。

## 五、正式上线：个人主体过不去，需要换主体

现在这个功能形态，**个人主体提审会被三条硬规则同时卡住**：

| 卡点 | 规则 | 影响的功能 |
| --- | --- | --- |
| 支付 | 个人主体不能开通微信支付 | 额度充值、会员 |
| AI 服务 | 「AI 问答 / 深度合成」类目不对个人开放 | AI 批改作业这个核心功能 |
| 教育类目 | 个人主体不能入驻教育服务；K12 学科类还需办学许可证 | 类目只能挂「工具」，功能与类目不符会被驳回 |

三条里任何一条都足以驳回，所以**内测阶段不要去提审**，浪费提交次数也影响后续。

### 建议的升级路径

| 方案 | 成本 | 能解决 | 备注 |
| --- | --- | --- | --- |
| **个体工商户**（推荐） | 注册免费，1-3 天 | 微信支付、深度合成类目、可做微信认证 | 最现实的 K12 工具类主体 |
| 企业主体 | 代理记账约 2000/年 | 同上，能力更全 | 打算长期做再上 |
| 保持个人 + 只做纯工具 | 0 | 只能做不含 AI 生成的功能 | 等于砍掉核心卖点，不建议 |

### 换主体后要补的清单

1. **小程序备案**（工信部强制，7-20 工作日）—— 后台首页「去备案」，个人也能备，但经营范围受限
2. **类目选择**：主体升级后选「教育服务 > 教育工具」或「工具 > 效率」，**不要选「学科培训」**（那需要办学许可证）
3. **虚拟支付**：额度充值必须走官方「小程序虚拟支付」，iOS 端由平台走苹果 IAP 结算，不能自己接微信支付
4. **AI 生成内容标识**：批改结果页需要标注「本结果由 AI 生成，仅供参考」
5. **注销入口**：目前只有协议里写了「联系邮箱申请」，正式上线前要补一个页面内可点的注销流程

> 这些不是现在要做的。现在做只会拖慢内测。等内测反馈确认产品值得做，再动主体。

## 六、常见问题

**真机上首页一直转圈，或者一片「网络请求失败」**
按顺序查：`curl https://sh-api.rstu.top/api/v1/health` 通不通 → 微信后台三个域名填了没 → `CURRENT` 是不是 `prod` → 体验版是不是最新上传的那个。

**拍照按钮点了没反应**
99% 是隐私保护指引没配。去后台补「选中的照片或视频信息」和「摄像头」，重新进小程序。

**提示「不在以下 request 合法域名列表中」**
域名填错或没保存。必须是 `https://sh-api.rstu.top`，不能带路径、不能是 IP、不能是主域名。

**批改一直卡在处理中**
worker 没起或 AI Key 没配：

```bash
docker compose ps worker
docker compose logs -f worker | head -50
grep AI_API_KEY .env | sed 's/=.*/=***/'
```

**额度显示 0 次**
老账号的 `free_total` 还是旧值，执行第二节第 1 步的 UPDATE 语句。

**改完配置多久生效**
域名配置一般 5-10 分钟。改了代码要**重新上传并重新设为体验版**，体验版不会自动更新。
